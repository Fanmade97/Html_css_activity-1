# Bella Vista Ristorante - Webpage Project

> **Project Group:** Group 1  
> **Assigned Project:** 2. Restaurant Website  
> **Course / Activity:** Creative HTML & CSS Webpage Projects (Activity 1)

---

## 🍽️ Project Overview
**Bella Vista Ristorante** is an authentic Italian and Mediterranean fine-dining promotional webpage. Built with clean semantic HTML5 and modern responsive CSS3, this website provides a luxurious dining ambiance, showcasing artisan heritage, seasonal dishes, table reservations, customer reviews, and location information.

---

## ✨ Features Included
- **Sticky Navigation Bar:** Fluid navigation with logo, section links, and quick CTA button.
- **Immersive Hero Section:** Full-width background image with gradient overlays, badge, punchy typography, CTA buttons, and key restaurant statistics.
- **Our Heritage / Story:** Rich visual layout with an overlapping floating badge, chef credentials, and farm-to-table core values.
- **Chef's Signature Special Offers:** Highlighted discount cards featuring preparation time, price comparisons, and high-resolution food imagery.
- **Curated Food Menu:** Categorized menu grid (Primi, Secondi, Dolci, Vini) with dotted price alignments and dietary badges (Gluten-Free, Vegetarian, Seafood).
- **Patron Reviews:** Multi-column testimonial grid with 5-star ratings, guest avatars, and verified customer commentary.
- **Interactive Reservation Form:** User-friendly booking form with party size selector, preferred dining time, date, and special requests.
- **Location & Opening Hours:** Clean informational card with service hours, valet information, and map mockup.
- **Comprehensive Footer:** Newsletter subscription, brand mission, and links.

---

## 💻 Tech Stack
- **HTML5:** Semantic markup (`<header>`, `<nav>`, `<section>`, `<article>`, `<form>`, `<footer>`).
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, animations, and media queries.
- **Typography:** Google Fonts (`Playfair Display` & `Plus Jakarta Sans`).
- **Responsive Design:** 100% responsive across mobile, tablet, and desktop viewports.
